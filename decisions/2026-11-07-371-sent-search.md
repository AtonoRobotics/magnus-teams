# Authorize and audit sent-search reads (#371)

Same treatment destination previews got in #184: `mailed_before` now
runs its own access check, pin validation and policy decision, audited
as a Decision of its own (stage `mailed_before`, call `sent:{call_id}`),
before the connector's sent search is touched.

Whatever stops the read still counts as not mailed: the send asks
rather than passing on an unchecked claim. So Deny and Ask both audit
and return false; only Allow proceeds to the provider. The dev trace
labels `sent:` calls as the gate's sent search, beside `preview:`.
