# A review that changed nothing needs no review (2026-11-07)

- A proactive review or a poll that started no work (`work_started` false: it only read and wrote run records such as `observe`, `interrupt` and `propose_schedule`) completes on `task_complete` as one without a contract, whatever contract it wrote. Reason: the owner got a review card from a background review that found nothing, asking him to check "Choose an appropriate response based on the supplied unfinished work"; the person asked for nothing, nothing changed in the world, and the criterion is the review's own judgement, which no one can check. The behavior spec says a review that decides nothing produces no output.
- A review that acted under a grant started work, so its criteria are checked as any task's, a person's review included (K37). Invariant 7's own test is a person's task and is unchanged.
- Background work (a review or a poll) never waits on its person (owner, 2026-11-07: "I should not get notifications and approvals for magnus trying to decide if there is something to notify me about"). A background run that would suspend for any reason but the kill switch fails instead, and the log keeps why for the run inspector; an action that would need approval is refused back to the run, telling it to suggest the work instead; an unchecked criterion completes it; a failure sends no notice; background tasks leave Tasks and the per-person controls. The sweep also ends background runs and puts away their non-output cards left waiting from before this change. Reason: each of those exits assumed a person was waiting, and a stopped review held every later review for its person. This is containment; the background lane in the Background Work Spec replaces the review loop.
