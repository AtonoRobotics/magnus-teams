# A pull request's tests reach compiled prompts and every Google connector (2026-11-06)

- `release/ci-select.sh` takes a Markdown file for a document only when no tracked Rust source names it in `include_str!`; a compiled one reaches what any other file at its path reaches, so the agent's and the chat's instructions and character (`crates/magnus/instructions/`) select every suite, as a kernel change does (#190). The list is derived from the sources, not written down, so a new compiled prompt cannot be missed; master still runs everything. Reason: the leading `*.md` rule took those prompts for documents, so a change to `agent.md` ran no tests. Test: `ci.rs` `a_compiled_prompt_runs_the_tests_of_the_code_that_compiles_it` (fails on master: `agent.md` selects `MAGNUS_SELECT=none`).
- A change to the shared Google client (`brokered/google`) also runs every connector whose `Cargo.toml` depends on it, each with its own crate and scratch tests, found from the manifests (today Calendar and Google Chat) (#190). Reason: it ran the client's crate and a scratch pattern, but not the Calendar or Google Chat crates, so a client change could break Google Chat untested. Test: `ci.rs` `a_change_to_the_shared_google_client_runs_every_connector_built_on_it` (fails on master: it does not run `package(=magnus-calendar)` or `package(=magnus-chat)`).
