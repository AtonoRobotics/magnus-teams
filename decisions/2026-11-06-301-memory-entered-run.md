# Whether a run carried its person's memory is recorded with each call (2026-11-06)

- Each model call records whether its system context carried anything of its person's (`ContextRef::personal`, in the `model_call` event), and the run keeps it (`Run::personal`, set by any call). What the run files to the knowledge base or writes into an org document is the person's (#258) when it is set. Before, the check reread the person's context at the write: a person who removed their only note while a call that carried it was out made the reply's write readable by everyone, with the note's words in it. Recorded in the log, it holds after a restart too. Reason: Codex's review of #298; #301. Test: `knowledge.rs` `a_note_removed_while_its_call_is_out_still_makes_what_it_files_theirs`.
