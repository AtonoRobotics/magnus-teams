# Wave 1.5: Unified SSRF blocklist, tamper-proof subresource learning, and scrubber hardening

**Choice.**
1. Extract [`crates/magnus/src/net_guard.rs`](../crates/magnus/src/net_guard.rs) as the single Rust SSRF/non-public IP blocklist shared by `web.rs` and `computer/egress/mod.rs` (parity with `browser/destinations.js`: `0.0.0.0/8`, `192.0.0.0/24`, `198.18.0.0/15`, `240.0.0.0/4`, multicast `224/4` & `ff00::/8`, NAT64 `64:ff9b::/96` & `64:ff9b:1::/48`, 6to4 `2002::/16`, Teredo `2001::/32`, IPv4-compatible `::/96`, IPv4-mapped `::ffff:0:0/96`, and site-local `fec0::/10`), and pin all checked addresses via `reqwest::ClientBuilder::resolve_to_addrs` for dual-stack fallback.
2. Restrict `computer/egress/policy.rs::resources_of` to embedded resource elements (`<script src>`, `<link href>`, `<img src/srcset>`, `<source>`, `<iframe src>`, `<video>`, `<audio>`)—excluding `<a href>` navigation links. For SPAs, learn additional subresource hosts only from the response bodies of the exact script/style URLs referenced in an open page's own HTML, strictly 1 level deep and capped by `MAX_LEARNED_HOSTS_PER_PAGE = 32` (never trusting guest request headers like `Sec-Fetch-Dest`, and never learning from off-page CDN scripts).
3. Guard `*.{host}` subdomain grants in `computer/identity.rs` with `net_guard::may_grant_subdomains` so multi-tenant public suffixes (`github.io`, `s3.amazonaws.com`, `vercel.app`, etc.) receive exact-host access only.
4. Harden `compartment/query_gate.rs` to inspect URL path/query segments for opaque secret tokens while allowing normal hyphenated URL slugs, and extend `computer/egress/surrogate.rs::Scrubber` to match hex, URL-encoded, JSON-escaped, and all 3 shifted base64 alignment variants (standard and URL-safe) of active secrets.
5. Keep the inbound `INJECTION_PHRASES` flag intact (preserving `inv4_taint.rs`), and narrow `safety.rs::screen_definition` so when a screening model is configured, phrase hits add a context note for the screener instead of hard-failing benign tool documentation outright.

**Reason.** Closes SSRF/transition-range gaps between Rust and `browser/destinations.js`, prevents over-broad `<a href>` and chained CDN host learning from hostile VMs, blocks encoded surrogate echoes and URL-embedded secrets, and removes false-positive tool-definition rejections when a screening model is present.
