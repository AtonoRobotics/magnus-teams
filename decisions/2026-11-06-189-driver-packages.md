# The installed-app drivers install every missing package (2026-11-06)

- The "Installed-app drivers" step calls `release/ensure-packages.sh WebKitWebDriver=webkit2gtk-driver xclip=xclip`, which adds the package of each missing command to one list and installs it with `sudo -n apt-get`, or installs nothing when every command is there. Reason: the inline step had lost its variable when it was written (commit ca6dc63d6 in #144, by a tool whose shell expanded `$pkgs` to nothing before the text reached the file), so it tested `[ -n "" ]`, ran `apt-get install -y` with no packages, and replaced the list with xclip instead of adding to it; a runner without WebKitWebDriver or xclip got neither. Test: `ci.rs` `the_installed_app_drivers_install_every_missing_package` (fails on the previous workflow: `left: ""`, no install requested).
- The test runs the step's own `run:` text from the workflow, as CI runs it, with only stub commands on the PATH, so the result does not depend on what this machine has installed. Reason: a test of the script alone would pass while the workflow still called the broken text. Test: `ci.rs` `the_installed_app_drivers_install_every_missing_package`.
- `release/ensure-packages.sh` stays unlisted in `release/ci-select.sh`, so a change to it runs everything, like `release/ensure-tauri.sh` and `release/ensure-windows-target.sh`. Reason: the step it serves runs only in a full run, and a full run includes this test. Test: `ci.rs` `the_installed_app_drivers_install_every_missing_package`.
