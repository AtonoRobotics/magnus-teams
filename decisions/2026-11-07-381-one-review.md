# One review per person per sweep, event first (#381)

Codex P2 on #370: the sweep checked for an active review once, then
could start a periodic review and an event review for the same person.
The per-person block now starts at most one: an event if one is due,
else the periodic one.

Event-first, not periodic-first: events are marked once handled, so the
cadence cannot starve them even at short cadences (periodic-first would
starve events entirely at `review_every_minutes` below the sweep's
granularity), and a waiting approval or coming schedule is the more
urgent review. An event review resets the cadence clock like any
review.
