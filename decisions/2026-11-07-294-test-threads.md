# Test suites run eight tests at once (2026-11-07)

- `test-threads = 8` in `.config/nextest.toml` (default and CI profiles), repeated as `--test-threads=8` on the two `cargo test` suites libtest runs (injection, installed-app), which do not read that file. Reason: #294 — with no cap, nextest ran 32 tests at once per suite; each scratch test drives an appliance with docker and sometimes a browser, and the 32-core build box hosts two CI runners plus the developers and the test services, so overlapping suites paged 16 GB to swap and held load past 100 until sign-ins and clicks timed out. Eight leaves headroom for a second suite, a build, and the box's people. Test: the capped profiles list and run the suites (config change; the proof is CI green with load near core count, watched on this pull request).
