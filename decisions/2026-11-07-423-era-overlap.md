# Untagged replays split by overlap (#423)

Codex P2 on #421, confirmed: #415 defaults every untagged event
to a delta, which rebuilds era-1 (fresh-only after the seed)
exactly — but era-2 (#411/#414: whole answers, no flag yet) then
unions where it should push, suppressing a later wake until two
tagged reads heal the window. The two eras share the same bytes
and are fundamentally ambiguous, except for one invariant: era-1
deltas are fresh-only, hence always disjoint from everything
known, while era-2 wholes usually overlap the previous answer.
The arm now pushes an untagged event that overlaps the window
union and unions one that is disjoint.

Era-1 stays exact under the rule; era-2 partial overlap pushes
correctly; mixed histories replay each event as itself. The
accepted edge is era-2 total churn (`{a}` then `{b}`), byte-shapes
identical to seed plus delta: it unions transiently and heals on
the next tagged reads. Pinned by test so the limitation stays a
conscious choice rather than drift.
