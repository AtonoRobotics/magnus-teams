# A grant's budget bounds every paid call of its tasks (#286, review of #284)

- One check, `Kernel::grant_spent` (`grants.rs`), says whether a run's grant has spent its budget for the period (and the person has not resumed the run past it). The agent loop's `may_ask_model`, the verifier (`verify.rs` `verifier_call`), the memory pass (`memory.rs`) and a knowledge extraction (`knowledge.rs` `extract_value`) each ask it before a paid model call. The agent loop stops the run with `grant_budget`; the others make no call, as they already do when the run's model calls are used up. Reason: these calls are charged to the grant (#280) but only the agent loop checked it, so a task could keep paying for the verifier and the memory pass after its grant was spent. Test: `standing_authority.rs` `a_spent_grant_stops_the_verifiers_calls_too` (the verifier's review of the contract that spent the grant is never asked for).
- A spoken answer (`write_spoken`) is not checked: the person asks for it themselves, and it is written for a chat answer, which runs under no grant.
- The verifier and the memory pass still check the run's own dollar budget only through the agent loop; bounding every request site by the run's own budget, and a request ahead of its cost, is #273.
