# Outlook's send is read back from Sent Items by its Internet message id

**Choice.** Outlook's `send_draft` reads the draft's `internetMessageId` (and that it is a draft) before it sends, sends it, and returns `{ sent, internet_message_id }`. A new read tool, `get_sent_message`, finds the sent copy in Sent Items by that id (`$filter=internetMessageId eq '…'`, the id quoted as OData quotes it) and returns it read whole, as `get_message` does. Graph files a sent message a moment after the send, so it looks up to `SENT_LOOKUP_ATTEMPTS` (5) times, `SENT_LOOKUP_WAIT_SECS` (2) apart, and then says the message is not in Sent Items yet, which the read-back records as "Not read back", not as a difference. The manifest declares `[read_back.send_draft]` with `get_sent_message`, its input `/result/internet_message_id`, and expects the subject and exactly the To, Cc and Bcc the gate read from the draft. The server image's digest in `catalog/microsoft-outlook.toml` is the image built from this change (`brokered/build.sh magnus-outlook`, on Strix Beta; the commit before it rebuilt to the old digest, so the build is reproducible there).

**Not compared.** The text, attachments and the gate's digest, which Gmail's read-back compares. Exchange sets who a message is from and may rewrite its body (line endings, HTML) as it sends, and nothing here has seen what a real mailbox's sent copy looks like; a false difference tells the agent a sent mail was not sent. They can be added once a run against a real mailbox shows the sent copy keeps them.

**Reason.** Spec rev 147 (Read-back) reads the world back after each irreversible action; `decisions/2026-11-12-evidence-not-contracts.md` left Outlook with none because Graph's `/me/messages/{id}/send` answers 202 with no body, and the copy in Sent Items has an id of its own. The Internet message id is assigned to the draft and kept when it is sent, so it names the sent copy without the send answering anything. Reading it from the draft rather than creating a new draft to send keeps the gate's approval on the draft the person saw.
