# Gemini API in the OpenAI-compatible adapter and native image generation

**Choice.** `magnus-adapter-openai` and `config/providers.toml` support Google's Gemini API (`id = "gemini"`, credential `gemini_api_key` in the vault) for both model turns (`https://generativelanguage.googleapis.com/v1beta/openai`) and native image generation and editing (`image_api = "gemini"`):

1. **Catalog and pricing.** Gemini's `/v1beta/openai/models` endpoint returns model ids prefixed with `models/` (`models/gemini-2.5-flash`). `parse_catalog` and `cost` strip a leading `models/` prefix so the model picker, `fixed_models`, `quote` and turn cost accounting match clean model ids (`gemini-2.5-pro`, `gemini-2.5-flash`, `gemini-2.5-flash-lite`) whether or not the caller or response includes `models/`.
2. **Error classification.** Gemini's OpenAI compatibility layer wraps error payloads in a single-element JSON array (`[{"error": {"code": 400, "message": "...", "status": "INVALID_ARGUMENT"}}]`). `classify` unwraps a top-level array and reads `error.status` alongside `error.type` and `error.code`.
3. **Images (`image_api = "gemini"`).** When `[images] adapter = "gemini"` is set (for example with `fast_model = "gemini-2.5-flash-image"` and `premium_model = "gemini-3-pro-image-preview"`), `images::make` strips a trailing `/openai` from `base_url` and posts to `/models/{model}:generateContent` with `generationConfig.responseModalities = ["TEXT", "IMAGE"]` (and `inlineData` on an edit), authenticating API keys with `x-goog-api-key` and reading the resulting image from `candidates[0].content.parts[*].inlineData.data`.

**Reason.** OpenAI-compatible providers share `magnus-adapter-openai` (`DECISIONS.md`), while Gemini's `/v1beta/openai/images/generations` endpoint covers generation only and not `image_edit` or multimodal image models (`gemini-2.5-flash-image`). Routing `image_api = "gemini"` to `:generateContent` inside the same adapter lets one vault secret (`gemini_api_key`) serve chat, tasks, `image_generate` and `image_edit` with no new adapter binary or wire change.
