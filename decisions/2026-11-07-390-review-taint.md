# Event reviews inherit the ended run's taint (#390)

Codex P1 on #387: the wake carried the outcome but dropped the taint,
so a review reading a tainted outcome started clean and could act on
it, or store it, untainted. The ended run's label now rides the wake
(`Ended.label`) into the review run's initial label, the same plumbing
task creation uses for any starting taint.
