# A run carries the notes in force when it started (2026-11-07)

- `person_context` reads the person's notes as of `run.created_at` (`relationship_at`, through a new `Log::bundle_at`: the path's latest write or removal strictly before a time), instead of the live document. Reason: a correction made mid-run reached the run's later model calls, so one run reasoned from two versions of the person's instructions (#259); reactions, disagreements (#233), the suggestion ledger (#253) and commitments (#236) were already read as-of-start, and the notes were the one piece that could change under a run. The app's notes view, the edit base and the tool result still read the live document. A removal in force at run start means no notes.
