# Cancels and pauses say how; every Magnus message takes reactions (2026-11-07)

- Cancel, pause, resume, edit and schedule-remove events record `source` ("button", "conversation", "console") and, for conversation, the chat run as `turn` (#267). Reason: the spec's alpha instrumentation counts cancellations and pauses by button or by conversation. The control methods take the turn (`None` from the app's buttons, the run from chat); the console passes "console"; the kernel's automatic pauses and resumes pass neither. `None` on old rows means predates the field. Tests: `chat_controls.rs` `a_cancelled_runs_log_says_button_or_conversation` (run logs plus the log's own pause rows; fails without: no source or turn), `controls.rs` `a_controls_event_names_conversation_or_button`.

- Reactions open to started-tasks entries and all six card kinds; the person's own messages and openers stay excluded (#267). Reason: the spec — users react to any Magnus message. A reaction on tasks reads its turn's run, on a card the run that proposed it (cards live in run results with no state link, so the run context indexes them when one carries a reaction). Test: `reactions_disagreements.rs` `started_tasks_and_cards_take_reactions` (200s, shown, and in the next run's context), `reactions.rs` `reactions_on_tasks_and_cards_read_their_run` (resolution plus hidden-card dropout).
