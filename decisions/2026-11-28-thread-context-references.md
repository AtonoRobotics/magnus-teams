# Thread context references

New chat turns and tasks record a thread boundary and, when applicable, an originating run or a selected entry. Inference gets bounded recent excerpts, the unabridged request, and a paged conversation history tool. History is recalled through the person's content wall and follows what remains visible in the thread. Old inline history remains readable.

Evidence from earlier turns travels separately from the request that delegates work. Auto Review, destination resolution, and web provenance use that request and the runtime's separately recorded grants and scope. Server follow-ups still carry the original objective when one is available. A user who selects their own message explicitly makes it the task's request.
