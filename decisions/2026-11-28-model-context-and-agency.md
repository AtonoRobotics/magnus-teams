# Model context and agency

Give Magnus the request, available capabilities, evidence, and output protocol. Injected instructions can describe the work and how the runtime behaves. The model chooses how to reason and act within that scope. Keep permissions, action receipts, and run state in the kernel. Ordinary task prose does not require a synthetic tool-call reminder.

The memory pass sees the new user message, bounded recent context, and relevant saved facts. A reviewer outage, exhausted allowance, or unreadable payload blocks that action and returns the reason to the model. Only an actual request for a person's decision opens an approval through Auto Review.
