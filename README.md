# Magnus

An autonomous digital worker. It runs on a server, has its own computer with a desktop, files and a browser, and works with people and other agents in a shared team workspace. People use it through a desktop app for Linux and Windows, or a browser.

- `AGENTS.md`: how to work in this repository.
- `docs/`: connectors, the admin console, remote access, proposals and research.
- `decisions/`: every choice with its reason.
- `desktop/README.md`: building the app.
