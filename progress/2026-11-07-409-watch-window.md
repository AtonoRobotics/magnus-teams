# Watched baseline window (#409)

Replaced the accumulating capped baseline with the last two
answers' id sets: `watched_seen` is now a per-watch window
(`Vec<HashSet>`, newest last, truncated to two), `note_watched`
diffs against the union of the window and records the full answer
on a started wake, and the five-thousand cap with its arbitrary
eviction is gone. `WatchedSeen`'s doc now says window.

Tests in `new_items.rs`: the window forgives a one-read absence but
wakes when the item returns after two reads away, and a fifty-one
hundred-id answer repeated wakes nothing. Both failed before the
fix — the large one with "the unchanged answer woke a review",
the window one on its final wake. Shared setup factored into
`watching_script` / `watched_app` / `msg` helpers. Full suite:
new_items 3, proactive 9, reviewer 6, magnus lib 116, inv4 11,
inv7 5, workspace check clean.

Note: the scratch harness spawns `magnus-appliance` as a binary,
so lib edits need `cargo build --bins` before the tests see them —
the first post-fix run failed on the stale binary.
