# The build box keeps its disk (2026-11-06)

The installed-app tests now give each session a temporary directory inside its home, so an AppImage they stop unpacks there and goes when the session ends, instead of leaving about 260 MB in /tmp. `release/ci-clean.sh` also removes AppImage extractions unpacked three hours ago or more and prunes the Docker build cache no build has used for three hours. Every workflow checks for 25 GB free as it starts (`release/ci-disk.sh`) and fails there, saying why, when the disk is short.
