# Scheduled watch polling (#406)

Watches gain optional `poll_minutes` (`Watch`, serde default keeps
old configs working). New `Ev::WatchPolled` + `watch_last_polled`
clock per person/app/tool, with erasure. `poll_due` runs from the
sweep loop beside `review_due`: due watches start one poll run each
— actor `poll`, minimal budget, instruction naming the exact
`app__tool` call. New `Task.poll` flag: contract-free completion,
no fast/backstop wake on ending, excluded from review context and
from the task list, search and home feed; `task_row` carries the
flag for single-task audit. Loop governance untouched: polls are
plain reads, governed as normal tool calls.

Test `watch_poll.rs`: with a 1-minute watch seeded by one task read,
a new message with no further reads wakes "1 new in mail" on the
next poll, and no poll row reaches `/v1/tasks`. Failed before the
fix (150s timeout, no wake); passes in ~61s after. Harness gains
`Spec::watch_poll`. Full gate: watch_poll 1, new_items 1, home 1,
proactive 9, reviewer 6, magnus lib 116, inv4 11, inv7 5, workspace
check clean; chat_controls shows only its 2 known pre-existing taint
failures (status/taint assertion, unrelated).
