# Erasure drops baselines and marks (#412)

Four retains in the `PersonErased` arm: `watched_seen` and
`home_last_open` by person, `items_opened` and `items_resolved_at`
by collected item ids. Unit test in `state.rs` seeds all four,
erases, and asserts all empty — failed before ("the erased
baseline stayed"), lib 117/117 after, workspace check clean.

The Keycloak-backed `person_erasure` suite cannot run in this
sandbox (its browser never reaches the loopback callback; it fails
in sign-in setup, before any erasure code, and passes on master
CI). CI is the gate for that suite.
