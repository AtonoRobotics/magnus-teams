A pull request that changes a prompt the kernel compiles in (`agent.md`, `chat.md`, `character.md`) now runs every suite instead of none; the selector finds such files from the `include_str!` calls, so a new one is covered without a list to keep. A change to the shared Google client now also runs the Calendar and Google Chat connectors, found from their `Cargo.toml` dependencies. Both are covered by new tests in `tests/scratch/tests/ci.rs` that fail on the old selector.
