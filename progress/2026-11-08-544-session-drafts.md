# Session-only message drafts

Replaced the durable draft journal in `desktop/ui/app.js` with an in-memory store, and rewrote the composer's send path around it. The draft status line, Discard local draft, the submitted-message cards, the Drafts navigation group and the `#/draft/…` route are removed, along with their CSS. `draft-check.mjs` now checks the in-memory store and fails on master, because the journal's create/submit/flush still exist. `workspace-continuity.mjs` checks session drafts across navigation, uploads, removal that never deletes the shared file, focus and history, IME, text typed during a send surviving it, a lost reply without a resend, rejection, anchors and sign-out. `flow.mjs`, `model-picker.mjs` and `workspace-layout.mjs` no longer depend on the journal. The unit check passes locally; the browser and installed-app checks run in CI.
