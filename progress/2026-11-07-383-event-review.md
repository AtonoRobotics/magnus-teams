# Event reviews see the ended task (#383)

## What changed

- `run/memory.rs` (`after_end`): the wake carries `(task_id, outcome)`.
- `proactive.rs`: `review_wake`/`start_review` take the ended task;
  `review_context` opens with it; event dedup is per-task wake marks
  instead of the five-minute window.
- `state.rs`: the `ReviewWoken` handler marks `task {id}` wakes.
- `events.rs`: reason vocabulary documented.
- `tests/scratch/tests/proactive.rs`:
  `a_failed_task_wakes_a_review_that_names_it` fails a task and asserts
  a review names it and why. Red without (no wake reaches the review),
  green with. It drains the boot review first (#386).
