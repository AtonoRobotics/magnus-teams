# Authorize and audit sent-search reads (#371)

## What changed

- `crates/magnus/src/boundary.rs`: `mailed_before` takes the action,
  run and person, and authorizes the sent search (access, pin, pins
  table, own policy decision) with a Decision audit before calling the
  connector. Deny, Ask and errors return not-mailed, so the send asks.
- `crates/magnus/src/dev.rs`: trace labels `sent:` calls.
- `tests/scratch/tests/sent_provenance.rs`: forbidding the search at
  the task layer makes a mailed send ask with the denial audited and
  the provider untouched; an allowed search leaves its audit and the
  send passes with no card.
